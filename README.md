# Pawan Kumar Singh — Research Website

A static GitHub Pages site for a professional research/publications portfolio.

## Publish in about 5 minutes

1. Create a new **public** GitHub repository named:
   `githubpawankumar.github.io`
2. Upload `index.html` and `styles.css` from this package to the repository root.
3. Commit the files.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. GitHub will publish the site at:
   `https://githubpawankumar.github.io/`

## Before publishing

- Add direct links to journal/SSRN/DOI records only after they are public.
- Keep manuscript status accurate (e.g. "submitted", "under review", "white paper").
- Do not label a submitted manuscript as "published".
- Add Google Scholar only after your profile/publications are available there.
- You can replace the PKS monogram with a professional headshot later.

## Easy edits

Open `index.html` in any text editor. Each publication is a `<article class="pub-card">...</article>` block.
